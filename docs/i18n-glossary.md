# 영어 번역 용어집 (초안)

`/en` 영어판의 화면 문구는 이 표를 기준으로 번역한다. 같은 한국어는 어느 화면에서든 같은 영어로 옮긴다. 표에 없는 새 용어는 여기에 먼저 추가한 뒤 사용한다.

## 문체

- 영어는 짧고 친근하게 쓴다. 한국어의 "~해요"체는 평서문으로 옮기고, 지나치게 격식 있는 표현(“Kindly…”)은 쓰지 않는다.
- 버튼과 메뉴는 동사로 시작한다: Save, Suggest a place, Add photo.
- 대소문자는 문장형으로 쓴다: “Suggest a place” (O), “Suggest A Place” (X). 고유명사와 브랜드만 대문자로 시작한다.
- 숫자에는 단수와 복수를 구분한다: `1 place` / `24 places`, `1 map` / `9 maps`.
- 숫자와 날짜는 `en-US` 형식으로 표시한다(`1,234`, `Oct 27, 2026`).

## 번역하지 않는 것

- 브랜드: 팅맵 → **Ting map**. Hype → **Hype**.
- 사용자가 쓴 내용: 지도 제목과 설명, 추천 이유, 댓글은 원문 그대로 둔다. 번역은 이후 “번역 보기” 기능에서 다룬다.
- 장소 이름: 원문 그대로 두고, 영문 표기가 있으면 함께 보여 준다(예: 타코스탠드 · Taco Stand).
- 이용약관과 개인정보 처리방침의 본문: 처음에는 한국어 원문을 유지하고, 한국어판이 원본이라는 안내만 영어로 단다.
