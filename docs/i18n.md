# 다국어 (한국어 / English)

## 구조
- 한국어는 지금 주소 그대로 (`/maps/x`), 영어는 `/en`을 붙인 주소 (`/en/maps/x`)예요.
- 모든 페이지는 `src/app/[lang]/` 아래에 있어요. `src/proxy.ts`가 접두사 없는 주소를 내부적으로 `/ko`로 보내고, `/ko/...`로 들어오면 접두사 없는 주소로 돌려보내요.
- 헤더와 모바일 메뉴의 한/EN 버튼을 누르면 `lang` 쿠키에 선택이 저장돼요. 다음에 접두사 없는 주소로 들어오면 `/en`으로 이동해요.
- `api`, `auth`, `go`, `robots.txt`, `sitemap.xml`은 언어와 관계없이 주소가 하나예요.
- `next start --hostname 127.0.0.1`로 띄우면 Next가 프록시에 `localhost` 주소를 넘겨 `/ko` 재작성이 외부 요청으로 처리되고 무한 리다이렉트가 생겨요. 직접 서버를 띄울 때는 `--hostname`을 빼 주세요 (Vercel은 해당 없음).

## 문장 사전
- `src/i18n/dictionaries/ko.json`, `en.json`에 들어 있어요. 키는 `영역.이름` 형식이에요 (예: `map.saveCount`).
- 단어는 [i18n-glossary.md](i18n-glossary.md)를 따라요.
- VS Code에 i18n Ally 확장을 설치하면 코드 안의 `t("...")` 옆에 영어 문장이 보이고, 그 자리에서 고칠 수 있어요.
- `tests/unit/i18n.test.ts`가 영어가 빠진 키와 `{이름}` 자리 불일치를 잡아요.

## 코드에서 쓰는 법
| 어디서 | 방법 |
|---|---|
| 클라이언트 컴포넌트 | `const { t, lang } = useI18n()` (`@/i18n/client`) |
| 서버 컴포넌트, `generateMetadata` | `const t = await getTranslator()` (`@/i18n/server`) |
| 링크 | `import Link from "@/i18n/link"` (현재 언어 접두사를 자동으로 붙여요) |
| 라우터, 현재 경로 | `useRouter`, `usePathname` (`@/i18n/navigation`), 서버 `redirect(await localizedPath("/login"))` |

- 값 넣기: `t("map.creatorMap", { handle })` → `"Map by @{handle}"`.
- 복수형: 숫자를 `count`로 넘기면 영어는 `키_one`이 있을 때 1개용 문장을 써요. 숫자는 자동으로 `1,200`처럼 표시돼요.
- 강조나 링크가 문장 안에 있을 때는 문장을 나누지 말고 `rich()`를 써요.
  `rich(t("home.headline"), { hl: (chunk) => <span>{chunk}</span> })` + `"Maps where <hl>taste</hl> brings people together"`
- 데이터에서 오는 이름(지역, 카테고리, 정렬, 장소 분류): `t.data("region", "서울")`, `t.area("서울 · 성수동")`, `t.data("placeCategory", "카페")`. 사전에 없는 지역 이름은 영어에서 로마자로 바꿔 보여 줘요 (성수동 → Seongsu-dong). 지도 위 도·시·동 라벨도 같은 방식이에요.
- 서버 오류처럼 실행 중에 만들어지는 한국어 문장: `t.message(error.message)`. `server.*` 사전과 맞춰 번역하고, `{이름}` 자리는 어떤 값이든 맞춰요.

## 서버 오류 메시지
- API는 `/en` 밖에 있어서, 요청을 보낸 페이지 주소(Referer)로 언어를 판단해요. `src/server/http.ts`의 `failure()`가 응답 직전에 번역해요.
- 서버에 새 오류 문장을 추가하면 `server.*` 키로 ko/en 사전에도 넣어 주세요. 넣지 않으면 영어 화면에서도 한국어로 나와요.

## SEO 페이지
`/maps/[slug]/places`, `/places/[id]`, `/areas/[area]` 경로 핸들러는 `lang`을 받아 `src/server/seo-pages.ts`에서 영어 HTML을 만들어요.

## 아직 번역하지 않은 것
- 지도 제목·설명, 장소 이름·주소·소개, 댓글, 프로필 소개, 지도 태그 같은 사용자 콘텐츠는 원문 그대로 보여요.
- 홈 카탈로그의 지도 제목과 추천 문구(`src/domain/catalog-config.ts`, 관리자 홈 콘텐츠)도 콘텐츠라 한국어예요.
- 지금 화면에 쓰이지 않는 컴포넌트(`desktop-discovery`, `discover-maps`, `mobile-discovery`, `mobile-map-story`, `mobile-theme-card`, `proposal-notice`)와 미리보기용 데모 데이터(`src/server/demo.ts`)는 번역하지 않았어요.

## 검색 노출
`src/i18n/metadata.ts`의 `indexedLocales`가 `["ko"]`인 동안 영어 페이지는 `noindex`이고 hreflang도 나가지 않아요. 검수가 끝나면 `"en"`을 추가하세요.
