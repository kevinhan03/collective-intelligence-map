# 앱인토스 출시 전 점검

## 이번 코드 반영 범위

- 모바일 테마 지도는 기본으로 지도 보기를 열고, 지도 정보는 하단 시트로 분리한다.
- 핀을 누르면 먼저 간단한 장소 카드를 보이고, 사용자가 선택했을 때만 전체 상세 화면을 연다.
- Google 지도도 목록·지도 전환 등으로 컨테이너 크기가 바뀌면 자동으로 다시 레이아웃한다.
- Vercel Analytics에는 지도/목록 전환, 정보 시트 열기, 핀 미리보기, 상세 진입만 익명 집계한다. 장소·지도·사용자 식별자와 검색어는 보내지 않는다.

## 출시 전에 운영자가 확인할 항목

1. 실제 Google 또는 Kakao 렌더링 키를 허용 도메인으로 제한하고, 지도 표시·핀 선택·목록/지도 전환을 실기기에서 확인한다.
2. 서버 검색을 켤 경우 `GOOGLE_PLACES_ENABLED` 또는 `KAKAO_PLACES_ENABLED`와 대응 REST 키를 함께 설정한 뒤 `/admin/usage`의 검색 예산을 확인한다.
3. 운영자 계정으로 이메일 로그인, OAuth를 사용할 경우 OAuth 왕복과 앱 복귀 흐름을 확인한다.
4. 작은 화면과 안전 영역이 있는 iOS/Android 기기에서 하단 미리보기·상세 화면·정보 시트의 닫기와 스크롤을 확인한다.
5. 토스 개발자 콘솔에서 앱 URL, 허용 도메인, 로그인 리디렉션 URL, 출시 심사를 위한 서비스 정보를 등록한다. 콘솔 등록값은 실제 배포 도메인이 정해진 뒤 입력한다.

## 검증 기준

- 핀 선택 뒤에는 미리보기 카드가 보이고, 카드의 상세 보기에서 전체 화면으로 이어진다.
- 상세를 닫으면 이전 핀의 미리보기로 돌아간다.
- 지도 SDK를 불러오지 못해도 목록은 계속 사용할 수 있다.
- 분석 대시보드에서 `community_view_changed`, `place_preview_opened`, `place_detail_opened`의 수를 비교해 지도에서 상세까지의 이탈을 확인한다.
