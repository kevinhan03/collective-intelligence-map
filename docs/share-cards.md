# 링크 공유 카드

홈과 지도 링크의 OG/Twitter 이미지를 1200×630 JPEG 카드로 제공한다. 기존 네이비·라임 색상, 팅맵 로고, SUIT 글꼴과 보유 대표 사진을 사용한다.

- 홈: `/og/home.jpg?v=1`. 라멘·빈티지숍·서울 야경 사진 3장과 “취향이 모이는 지도” 문구를 조합한다. 빌드 시 미리 생성하며 공개 캐시는 하루다.
- 지도: `/og/maps/{slug}/image.jpg?v=1-{revision}`. 현재 편집 설정의 제목·사진·초점 위치를 사용한다. 크리에이터 지도는 작성한 제목·커버를 유지한다. 사진이 없거나 읽기 실패 시 로고와 제목을 표시한다.
- 이미지 위에는 지역/분류와 지도 제목을 표시한다. 소셜 제목은 `지도 제목 | 팅맵`으로 간결하게 제공한다. 기존 검색용 문서 제목·설명·canonical은 유지한다.
- 업로드한 편집 이미지에는 익명 `catalog_image_access` 권한 검사를 사용한다. 지도 이미지는 공개 지도 조회를 통과한 뒤에만 생성/304 응답하며 비공개 지도는 404다. 소유자 세션을 공유 이미지 읽기에 전달하지 않는다.
- 카드 생성 결과는 서버에서 5분 캐시하고 `public-community` 무효화를 따른다. 숫자 통계는 이미지 키에서 제외한다. 사진·제목·초점 변경은 새 revision URL을 만든다. 이미지 응답은 private/no-cache로 재검증한다.
- 외부 주소를 임의로 가져오지 않는다. 정적 사진은 public 내부의 허용 이미지 형식만 읽고, 업로드 이미지는 기존 Storage 버킷으로 제한한다.
- 새 이미지 경로는 `.jpg`로 끝나 다국어 proxy가 적용돼도 이미지 요청이 페이지 언어 경로로 재작성되지 않는다.

## 검증

단위 232개, SEO/공유 브라우저 테스트 15개, 타입 검사, 프로덕션 빌드 통과. 전체 린트는 오류 없음(기존 prototype 경고 2개). 한국어 긴 제목 렌더링, 로고 픽셀, 비공개 업로드 대체 처리, 공개 지도 확인 후 304, 제목·사진 revision, 익명 이미지 다운로드와 이미지 크기를 검사한다. 서버 비밀 값이 클라이언트 번들에 포함되지 않음도 확인했다.

홈·라멘·버거·패션 샘플은 96~136KB였다. Next ImageResponse 결과를 JPEG로 압축하며 브라우저에 새 렌더링 라이브러리를 추가하지 않는다. 이미지 생성은 해당 이미지 URL에 접근할 때만 수행한다.

템플릿·고정 사진을 변경하면 `HOME_SHARE_IMAGE`와 지도 이미지 URL의 버전 `v=1`도 올린다. 이미 게시된 소셜 링크는 플랫폼이 보관한 미리보기를 계속 사용할 수 있으므로, 배포 후 새 링크 수집 결과와 기존 게시물의 갱신 여부를 구분한다.
