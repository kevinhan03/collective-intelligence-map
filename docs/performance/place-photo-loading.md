# 장소 사진 로딩 및 핀 전환 검증 (2026-10-25)

## 변경

- 핀 선택 즉시 사진 목록을 공유 캐시로 요청하고 첫 갤러리 사진과 배경 썸네일을 미리 로딩한다. 상세 패널을 지도 이동 후에 여는 데스크탑 대기를 없앴다.
- 갤러리는 최신순을 유지한다. 배경은 `created_at ASC, id ASC`로 선택한 가장 오래된 **공개** 사진이다. 갤러리 첫 페이지 밖의 사진도 배경이 될 수 있다. 목록과 배경 ID 조회는 병렬 실행하며, 배경 ID도 기존 장소별 30초 공유 캐시에 포함된다. 숨김/삭제된 첫 사진은 다음 공개 사진으로 대체된다.
- 배경은 eager/high priority로 로딩하고 페이드는 500ms에서 180ms로 줄였다.
- 공개 이미지 응답은 `private, no-cache`와 Storage 경로 기반 ETag를 사용한다. 매번 현재 공개 RLS와 상태를 확인한 뒤 304를 반환하거나 썸네일 바이트를 재사용한다. 서버 썸네일 캐시는 최대 8MiB/128개, 60초이며 권한 판정을 캐시하지 않는다. 관리자 이미지는 계속 no-store이다. 공개 버킷 전환이나 서명 URL 노출은 없다.
- 데스크탑 핀 전환은 380ms easeTo를 사용한다. 패널이 재생성돼도 위치/크기가 같으면 지도 위치를 재보정하지 않는다. 크기가 변하더라도 진행 중인 이동을 끊지 않고 완료 후 보정한다. 패널을 제외한 지도 중앙 정렬과 수동 드래그를 유지한다.

## 동일 조건 비교

실제 CommunityExplorer, MapLibre 렌더러, 공유 리소스 캐시, 사진/배경 컴포넌트를 브라우저에서 실행한다. 지도 배경은 네트워크 변수를 없앤 테스트 스타일이다. next/image는 기존 테스트용 img 대체 컴포넌트를 사용한다. 운영 서버에서 관측한 대기와 비슷하게 사진 목록 응답에 650ms, 썸네일 응답에 1800ms를 고정했다. 선택 시점부터 배경 이미지가 로드되고 CSS opacity가 1이 될 때까지 측정했다. 테스트 실행/폴링 비용도 포함된다.

| 상황 | 변경 전 1회 | 변경 후 3회 | 변경 후 중앙값 | 감소 |
|---|---:|---:|---:|---:|
| 첫 선택 배경 표시 | 4155ms | 2738 / 2736 / 2761ms | 2738ms | 1417ms (34.1%) |
| 다른 핀으로 전환 후 배경 표시 | 3387ms | 2867 / 2874 / 2881ms | 2874ms | 513ms (15.1%) |

첫 선택의 패널 표시 중앙값은 약 408ms였다(변경 전 1326ms). 사진 목록 요청은 A→B→A 전환에도 2회로 유지됐다.

이 결과는 **통제된 지연을 넣은 로컬 회귀 테스트**이며, 운영 배포 후 실측 개선율이 아니다. Playwright route interception은 HTTP 캐시를 비활성화하므로 재방문 배경 시간은 226~2360ms로 변동했다. 재방문 개선율은 이 수치로 주장하지 않는다. 서버 캐시가 없는 새 인스턴스의 최초 Storage 다운로드 지연은 남는다.

## 실제 데이터 읽기 검증

로컬 앱에서 공개 장소 ‘라까예’를 열어 실제 사진 2장과 배경의 이미지 디코딩 완료(`complete && naturalWidth > 0`)를 확인했다. 배경은 오래된 사진 `3ddbc062-902b-4ce9-8972-ed7171f6da14`, 갤러리 첫 사진은 최신 사진 `038aebca-5616-4821-8065-2c1c697511e4`였다.

같은 이미지 엔드포인트를 연속 조회했을 때 첫 요청은 200/34692 bytes, 이후 요청은 304/0 bytes였다(153ms, 36ms). 최초 요청 1143ms에는 개발 서버 컴파일·연결 준비 비용이 포함될 수 있어 감소율 비교에는 사용하지 않았다. 사진 및 운영 데이터는 변경하지 않았다.

## 반복 실행

```sh
npm run test:photos:performance
```

이 명령은 위 브라우저 로딩 테스트를 데스크탑에서 3회 반복한다. 각 결과는 콘솔의 `PHOTO_BENCHMARK`와 Playwright `photo-timings` 첨부에 기록한다. 숨김/삭제 후 이미지 캐시 차단, 관리자 접근, ETag 변경, 캐시 만료/용량 제한, 오래된 공개 사진 선택은 단위 테스트로 검증한다. 핀 중심 정렬(overlay/grid), 패널 교체 중 이동 지속, 수동 지도 이동은 MapLibre 브라우저 테스트로 검증한다.

최종 검증: typecheck / ESLint / production test build 통과, 단위 테스트 180개 통과, 전체 브라우저 테스트 192개 통과·64개 환경별 skip. 별도 3회 반복한 배경 로딩 및 overlay/grid 핀 전환 검사 9개도 모두 통과했다. 배포·커밋·푸시는 수행하지 않았다.
